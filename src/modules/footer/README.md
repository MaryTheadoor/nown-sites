# footer + conversion modules

Page-end chrome and the tiles that close a conversion.

| Tile | Purpose | Notes |
|---|---|---|
| `footer` | Site footer | `.tile-footer` (brand, cols, legal) |
| `contact` | Static contact info card | address/phone/email/links |
| `contact-form` | Form card | `data-form-provider`/`data-form-endpoint` (Formspree/Tally/StaticForms) |
| `map` | Leaflet + OpenStreetMap card | `data-center`/`data-zoom` |
| `search` | Pagefind full-text search tile | `data-index` |
| `event` / `calendar` | Scheduling tile | Cal.com/SavvyCal embed |
