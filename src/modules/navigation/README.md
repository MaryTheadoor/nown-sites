# navigation modules

Site chrome that appears on every page.

| Tile | Purpose | Notes |
|---|---|---|
| `nav-dock` | Floating pill navigation | Pill-shaped, glassmorphism, `.nav-dock`, wrapped in a fixed container |
| `announcement` | Top announcement strip | optional; `.tile-announcement` |
| `theme-toggle` | Dark/light switch | lives inside `nav-dock`; `.nav-dock-theme` |

See `docs/MODULE-SPEC.md` for the compliance rules.
